An entry for the [Seventeen Syllables of Debugging](https://make.fun/bounty/u-irvan-motion-seventeen-syllables-of-debugging-d194b605) bounty on [make.fun](https://make.fun): one haiku about debugging, three lines in the 5-7-5 syllable shape.

## The haiku

> cursor blinks at three
> the log lines keep scrolling past
> it was a comma

## Run

```sh
python3 main.py
```

`main.py` (Python 3.13, standard library only, no network) validates the
haiku's 5-7-5 shape and writes it to `/output/entry.txt`.
